## 2. About 顯示內容

| 欄位 | 需求與來源 |
| --- | --- |
| 軟體名稱 | SNMP Simulator，由產品／組件資訊取得 |
| 版本號 | 取本 App 的集中建置／組件版本，與主視窗及發布版本一致；不另維護一份固定版本字串 |
| Commit | 顯示實際建置來源完整 hash 的前 **7 碼**，例如 `583b1e5` |
| 授權類型 | 原創程式碼為 MIT，提供完整授權內容的查看入口 |
| 第三方授權 | 沿用既有內建聲明檢視能力，保留第三方元件原授權，不將全部標示為 MIT |
| 專案網址 | `https://github.com/Koala5978/SNMP-Simulator`，可由使用者主動開啟 |

顯示示例（僅示意排版，不代表已存在該版本的建置）：

```text
SNMP Simulator
版本：0.2.0
Commit：583b1e5
授權：MIT
```

入口位置、視窗排版與既有「授權聲明」按鈕如何整合，留待架構／UI 設計確認；不要求裝飾性版面、動畫或主題功能。

## 3. 功能需求

| 編號 | 需求 | 完成條件 |
| --- | --- | --- |
| AB20-01 | 提供 About 入口 | 可開啟／關閉，看到名稱、版本、commit、授權及專案網址；不影響模擬啟停或重設 uptime／統計 |
| AB20-02 | 畫面採短版 hash | 有有效建置來源時顯示完整 hash 的前 7 碼，不預設展開整串 hash；短碼只供顯示，不取代正式來源識別 |
| AB20-03 | 建置保留完整 hash | 由實際 checkout 的完整 commit 注入建置資訊；以確切 tag 建置時使用該 tag 指向的 commit，與 SOURCE_COMMIT.txt 一致；不可硬寫某次範例 hash |
| AB20-04 | 短碼可開啟來源 commit | 點擊 `583b1e5` 等短碼時，連結使用完整 hash：`https://github.com/Koala5978/SNMP-Simulator/commit/<full-hash>`，不依賴短碼解析 |
| AB20-05 | 複製軟體資訊 | 提供明確的複製按鈕，內容包含名稱、版本、**完整 hash**、MIT 與專案網址，便於 issue／對話回報；剪貼簿失敗有可理解的回饋 |
| AB20-06 | 離線與未知來源 | 開啟／顯示／複製不需連線；缺少有效 Git 資訊的本地建置顯示「未知」，不猜測 main 最新 commit，不將未知組成錯誤連結 |
| AB20-07 | 授權可讀取 | 可從 About 查看本專案 MIT 全文及既有第三方聲明，離線也能讀取；主授權與第三方授權分開呈現 |
| AB20-08 | 單一版本與回報來源 | About、主視窗、組件及發布資訊一致。複製內容不含 community、設備 IP、檔案路徑或其他使用者設定 |

完整 hash 保存於內建的建置／組件資訊，單獨攜帶 EXE 也可讀取；不以旁邊有無 SOURCE_COMMIT.txt 決定顯示。具體注入方式在架構階段決定。

7 碼可能在大型儲存庫產生相同前綴，因此回報／連結／發布來源核對均使用完整 hash；不在程式啟動時連線檢查唯一性。缺資料時的複製內容也標示未知，不編造識別值。

本地未提交變更不一定受 commit hash 涵蓋；架構階段需定義其呈現方式，不能把任意工作區誤標為已驗證的正式發布建置。

## 4. 不納入 About 的項目

- 自動更新、檢查新版本、遙測或使用統計上傳。
- 啟動時查詢 GitHub，以網路結果替代內建的建置資訊。
- 即時計算 EXE SHA-256。正式交付雜湊仍由發布流程提供 SHA256SUMS.txt，與 About 的 commit 識別用途分開。
- 將實際設備資料或環境秘密放入複製內容。
- 因加入 About 就變更 SNMP 行為、JSON schema 或 v0.2.0 其他功能範圍。

## 5. 驗收案例

以下皆為待實作／待驗證，不代表已執行。

| 案例 | 操作／情境 | 預期 |
| --- | --- | --- |
| AC20-AB01 | 開啟 About | 名稱、版號、短 commit、MIT 及專案網址皆可讀取，版號與 App 組件／主視窗一致 |
| AC20-AB02 | 以完整 hash `583b1e5654f70d387763722321f51355280e22fa` 作顯示測試 | 畫面為 `583b1e5`，複製內容保留完整 hash，不把此示例寫死為產品來源 |
| AC20-AB03 | 點擊短 hash | 開啟正確儲存庫與完整 hash 的 commit URL，不使用短碼 URL |
| AC20-AB04 | 按複製並檢查文字 | 包含指定軟體資訊及完整 hash；沒有 community／設備端點／設定檔路徑；剪貼簿忙碌等錯誤可處理 |
| AC20-AB05 | 離線執行單一 EXE | About、複製及授權全文仍可使用；僅主動點擊網址需要網路，不影響模擬 |
| AC20-AB06 | 無 Git 資訊或注入值無效的本地建置 | 顯示與複製皆標示未知，沒有錯誤的 commit 連結；不偽裝成正式來源 |
| AC20-AB07 | 使用正式 tag 的 CI 產物 | 內建完整 hash、SOURCE_COMMIT.txt 與 tag 的實際 commit 相符；畫面為同一值前 7 碼 |
| AC20-AB08 | 模擬執行中開關 About、查看授權及複製 | SNMP 仍正常回應，uptime／累計值不因 About 操作重設 |

顯示／截短／URL／複製文字可先做純邏輯測試；實際視窗、剪貼簿、瀏覽器開啟及單檔授權讀取需 Windows 整合驗證。來源識別採實際測試產物，不沿用舊版 hash。
